# AgroBloque - JT

Esta es una copia separada para JT Horticola.

## Importante

- No usa por defecto el Supabase de AgroBloque Gabriel.
- En Vercel hay que cargar variables propias de Supabase JT:
  - `REACT_APP_SUPABASE_URL`
  - `REACT_APP_SUPABASE_ANON_KEY`
- Antes de usar la app, crear un proyecto nuevo en Supabase para JT y ejecutar ahi los SQL necesarios desde la carpeta `supabase`.
- El usuario administrador se crea desde Supabase Auth del proyecto JT.

## Subida por GitHub

Subir el contenido de esta carpeta como proyecto independiente.
No subirlo encima del AgroBloque de Gabriel salvo que se quiera reemplazar esa app.
