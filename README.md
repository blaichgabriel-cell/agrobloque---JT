# AgroBloque - JT

Sistema de gestion agricola - JT Horticola

## Setup

1. Clonar el repositorio
2. Crear archivo `.env` en la raíz con:
```
REACT_APP_SUPABASE_URL=https://TU-PROYECTO-JT.supabase.co
REACT_APP_SUPABASE_ANON_KEY=TU_ANON_KEY_PUBLICA_JT
SUPABASE_SERVICE_ROLE_KEY=TU_SERVICE_ROLE_KEY_JT
```
3. `npm install`
4. `npm start`
